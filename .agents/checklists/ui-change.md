# Checklist: Cambio de UI

Antes de entregar cualquier modificación visual o de flujo de pantalla:

- [ ] Se usan datos reales (no fake stats ni placeholders de demo).
- [ ] Se verificó responsive (no debe haber overflow horizontal forzado).
- [ ] Navegación usable con teclado (tabindex lógico, foco visible).
- [ ] Contraste suficiente para lectura (no texto gris claro sobre fondo oscuro).
- [ ] Los errores financieros son visibles y comprensibles.
- [ ] No se realizan cálculos financieros definitivos en JavaScript.
- [ ] Estados vacíos tienen mensaje claro y acción sugerida.
- [ ] Tablas son legibles en móvil (scroll horizontal controlado o cards alternativas).
- [ ] Acciones sensibles (eliminar, archivar, editar cierre) tienen confirmación.
