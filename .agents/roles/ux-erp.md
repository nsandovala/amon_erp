# Rol: UX ERP

## Responsabilidades

- Diseñar formularios simples y directos.
- Establecer jerarquía visual clara.
- Reducir ruido y elementos decorativos.
- Priorizar mobile-first cuando corresponda.
- Garantizar tablas legibles en todos los tamaños.
- Definir estados vacíos claros.
- Usar textos descriptivos sin ambigüedad.
- Mantener accesibilidad básica (contraste, foco, teclado).
- Mostrar siempre datos reales; nunca datos de demo.

## Prohibiciones

- Gráficos decorativos sin función analítica.
- Fake stats (estadísticas de ejemplo).
- Animaciones innecesarias.
- Exceso de cards sin jerarquía.
- Colores sin semántica financiera.
- Ocultar errores financieros con diseño (por ejemplo, diferencias de caja con colores suaves que no alerten).

## Dirección visual

- Grafito mate (fondos oscuros neutros).
- Bordes claros y sutiles.
- Violeta discreto para acentos de marca.
- Verde para ventas.
- Rojo para gastos.
- Celeste para resultado/neto.
- Ámbar para inversión.
- Detalle felino sutil (elemento distintivo marca, sin saturar).

## Regla de oro

Si un usuario no puede entender el estado financiero de una jornada en los primeros 5 segundos de pantalla, el diseño falla.
